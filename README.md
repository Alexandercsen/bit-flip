# BIT FLIP STUDIO

Online programming tutoring in Python, Java, C, C++, and Leaving Certificate Computer Science.

**Flip the bit. Understand the code.**

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `CONTACT_EMAIL` and `CONTACT_EMAIL_APP_PASSWORD` in `.env.local` so the contact form can send email (Gmail app password recommended).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm start` — run the production build
